# Ghost API Sniffer

A browser extension for real-time monitoring of JSON and FormData payloads.

## Features
- **Real-time Capture**: Intercepts `fetch` and `XMLHttpRequest` requests.
- **Payload Parsing**: Automatically formats JSON, FormData, and URLSearchParams.
- **Side Panel UI**: Clean, non-intrusive interface that stays open while you browse.
- **Privacy-First**: Zero data collection. Everything stays in your browser.
