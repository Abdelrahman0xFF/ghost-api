# Privacy Policy for Ghost API

**Last Updated: April 27, 2026**

Ghost API ("we", "us", "our") is committed to protecting your privacy. This Privacy Policy explains how our Chrome/Edge extension handles data.

## 1. Data Collection
Ghost API **does not collect, store, or transmit** any personal data to external servers. All data intercepted (API payloads, URLs, and methods) is processed locally on your machine and stays within your browser's session.

## 2. Data Storage
- Intercepted data is stored in the browser's temporary memory (RAM).
- No data is saved to permanent storage (IndexedDB, LocalStorage, or Cloud).
- Closing the side panel or refreshing the tab clears the current session's logs.

## 3. Permissions Usage
- `sidePanel`: Used to display the captured data in a dedicated sidebar.
- `host_permissions` (`<all_urls>`): Necessary to intercept network requests on the websites you choose to inspect.

## 4. Third-Party Sharing
We do not share any information with third parties. There are no analytics, tracking scripts, or advertising modules included in this extension.

## 5. Contact
If you have questions about this policy, please contact the developer via the official repository.
